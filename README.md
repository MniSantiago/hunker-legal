# Hunker: soporte y privacidad

¿Tienes una duda, un problema o una sugerencia sobre Hunker? ¿Quieres ejercer tus derechos sobre tus datos?

**[Abre una solicitud aquí](https://github.com/MniSantiago/hunker-legal/issues/new)** y te responderemos lo antes posible. No incluyas datos personales que no sean necesarios: las solicitudes son públicas.

- [Política de privacidad](https://mnisantiago.github.io/hunker-legal/privacy.html)
- [Aviso legal](https://mnisantiago.github.io/hunker-legal/aviso-legal.html)
- [Ayuda](https://mnisantiago.github.io/hunker-legal/)

Para borrar tus datos no hace falta escribirnos: en la app, Ajustes → «Borrar mi cuenta y mis datos».
